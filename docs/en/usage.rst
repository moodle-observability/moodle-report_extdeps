Usage
=====

* *Site administration > Reports > External dependencies*: cards, courses, all occurrences and Run analysis.
* In a course: *Reports > External dependencies*. Use **Edit** to fix the place where the dependency is used and
  **Check now** to confirm the fix.
* A dependency that works for the students although it is reported as broken can be accepted as a false positive in
  its page; it goes on being checked but sends no alerts.
