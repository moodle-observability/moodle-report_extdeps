Uso
===

* *Administração do site > Relatórios > Dependências externas*: cartões, cursos, todas as ocorrências e Executar
  análise.
* No curso: *Relatórios > Dependências externas*. Use **Editar** para corrigir o lugar onde a dependência é usada e
  **Verificar agora** para conferir a correção.
* Uma dependência que funciona para os estudantes, mesmo aparecendo como quebrada, pode ser aceita como falso
  positivo na página dela: continua sendo verificada, mas não envia avisos.
